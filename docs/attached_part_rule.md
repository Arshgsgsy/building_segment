# Attached-part rule (guide §4.2)

Decide once, apply everywhere. Keep this open next to the editor while merging.

## Rule

An attached part (porch, wing, den, addition, shed) is **its own building** when
it is closed by a full-weight wall **and** has its own construction color or
story number.

It **belongs to the main building** when it is only separated by a thin line
inside the main outline.
